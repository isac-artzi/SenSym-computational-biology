2  Random variables, expectation, variance

None of this section is hard, and all of it will be used verbatim. Read it slowly once rather than quickly twice.

Definition · random variable

A random variable is a number produced by a random experiment. Formally it is a function from outcomes to numbers, but for our purposes: run the experiment, write down a number, and that number is $X$.

A random variable is discrete if the numbers it can take form a list $x_0, x_1, x_2, \dots$. All of our counts are discrete: a gene's count is $0, 1, 2, \dots$ and never $2.7$. The function $P(X = x)$ is its probability mass function (pmf); it is non-negative and sums to 1 over all possible $x$.

Notation, once and for all: capital letters ($X$, $Y$) are random variables; lower-case letters ($x$, $k$) are particular values they might take. "$P(X = 3)$" is a number; "$X$" is not.

Definition · expectation The expectation (or mean) of a discrete random variable is the probability-weighted average of its values: $$E[X] \;=\; \sum_{k} k \, P(X = k).$$ It is a fixed number, not a random one. Two properties, both used constantly:
  • Linearity: $E[aX + b] = aE[X] + b$, and $E[X + Y] = E[X] + E[Y]$ for any $X$ and $Y$, independent or not (you proved this in Week 1, worked derivation 1).
  • Law of the unconscious statistician: for any function $g$, $E[g(X)] = \sum_k g(k) P(X = k)$. You do not need the distribution of $g(X)$; you reweight the distribution of $X$. We use this with $g(x) = x^2$.
Definition · variance The variance is the expected squared distance from the mean: $$\mathrm{Var}(X) \;=\; E\big[(X - E[X])^2\big] \;=\; E[X^2] - (E[X])^2,$$ and the standard deviation is $\mathrm{sd}(X) = \sqrt{\mathrm{Var}(X)}$, which is in the same units as $X$ (molecules, not molecules-squared). Two properties:
  • $\mathrm{Var}(aX + b) = a^2\,\mathrm{Var}(X)$. Shifting does nothing; scaling squares.
  • $\mathrm{Var}(X + Y) = \mathrm{Var}(X) + \mathrm{Var}(Y)$ only when $X$ and $Y$ are independent (Week 1, exercise 1.4). This asymmetry with expectation is the single most important structural fact in the next four weeks.

The middle expression in the variance definition is the honest one; the right-hand one is the computational one. They agree because expanding $(X - \mu)^2 = X^2 - 2\mu X + \mu^2$ and taking expectations term by term gives $E[X^2] - 2\mu E[X] + \mu^2 = E[X^2] - \mu^2$, using linearity and the fact that $\mu = E[X]$ is a constant.

The one example everything is built from · a single coin flip

Let $I$ be $1$ with probability $p$ and $0$ with probability $1-p$. This is a Bernoulli, or an indicator variable. Then

$$E[I] = 1\cdot p + 0\cdot(1-p) = p.$$

For the variance, note that $I^2 = I$ (because $0^2 = 0$ and $1^2 = 1$ — this trick is worth remembering), so $E[I^2] = E[I] = p$, and

$$\mathrm{Var}(I) = E[I^2] - (E[I])^2 = p - p^2 = p(1-p).$$

Note the shape of $p(1-p)$: zero at $p = 0$ and $p = 1$ (a coin that always does the same thing is not random), maximal at $p = 1/2$. Every variance in this project is ultimately a sum of these.

3  The binomial, derived

Now the model. A cell of type 1 has a fraction $p$ of its transcripts belonging to some gene $g$. The sequencer captures $D$ molecules, each one drawn independently, each one landing on gene $g$ with probability $p$. Let $X$ be the number of the $D$ captured molecules that turn out to be gene $g$.

Definition · the binomial distribution $X \sim \mathrm{Binomial}(D, p)$ if $X$ counts the successes in $D$ independent trials, each with success probability $p$. Its pmf is $$P(X = k) = \binom{D}{k} p^k (1-p)^{D-k}, \qquad k = 0, 1, \dots, D,$$ where $\binom{D}{k} = \dfrac{D!}{k!\,(D-k)!}$ counts the ways to choose which $k$ of the $D$ trials succeeded. The three factors are: which trials succeeded, the probability that those ones did, and the probability that the others did not.

You could get $E[X]$ and $\mathrm{Var}(X)$ by grinding through $\sum_k k \binom{D}{k} p^k(1-p)^{D-k}$ with a factorial identity. Do not. There is a route that is shorter, more memorable, and — crucially — makes visible exactly which step needs independence.

Theorem · mean and variance of a binomial  proved If $X \sim \mathrm{Binomial}(D, p)$ then $$E[X] = Dp, \qquad \mathrm{Var}(X) = Dp(1-p).$$
Proof · by indicator decomposition

Let $I_i = 1$ if trial $i$ succeeded and $0$ otherwise, for $i = 1, \dots, D$. Counting the successes is the same as adding up the indicators:

$$X = I_1 + I_2 + \cdots + I_D.$$

That single line is the whole idea. It converts one complicated variable into a sum of $D$ copies of the simplest possible variable, whose mean and variance we computed above.

The mean. Expectation is linear, always, with no conditions:

$$E[X] = \sum_{i=1}^{D} E[I_i] = \sum_{i=1}^{D} p = Dp.$$

The variance. The trials are independent by assumption, so variances add (Week 1, exercise 1.4 — the covariance terms vanish):

$$\mathrm{Var}(X) = \sum_{i=1}^{D} \mathrm{Var}(I_i) = \sum_{i=1}^{D} p(1-p) = Dp(1-p). \qquad \blacksquare$$

Assumptions used: (i) each molecule is captured independently of the others; (ii) every molecule has the same probability $p$ of belonging to gene $g$; (iii) $D$ is fixed in advance, not itself random.

Look at what the two halves of that proof cost. The mean needed nothing. The variance needed independence, and it needed it at exactly one step. If molecules were captured in clumps — one capture event pulling in several copies of the same transcript — the $E$ line would still be true and the $\mathrm{Var}$ line would be false, and the variance would come out too big. Hold that thought until Week 11, where real data does precisely this.

Assumption (iii) is doing more work than it looks Real sequencing does not deliver exactly $D$ molecules per cell: library sizes vary from cell to cell, sometimes by a factor of three. Everything in this project conditions on $D$ — that is, it asks "given that this cell yielded $D$ molecules, what follows?" — and then compares cells at matched depth. Week 10 makes that matching explicit by downsampling every cell to a common depth, which is legitimate because of the thinning theorem in section 6. If you ever find yourself comparing a cell with $D = 5000$ to one with $D = 1500$ without normalizing, you are measuring library size, not biology.

4  The Poisson limit

The binomial is correct but awkward: it has two parameters, its pmf contains a factorial of $D$ (which for $D = 3000$ is a number with over 9000 digits), and its variance $Dp(1-p)$ depends on both parameters separately. In our regime it collapses into something much better behaved.

The regime is: many draws, each unlikely to hit our gene, with a fixed expected count. Formally, let $D \to \infty$ and $p \to 0$ together in such a way that $Dp = \lambda$ stays fixed. Then $p = \lambda/D$, and we ask what the pmf converges to.

Theorem · the Poisson limit  proved Fix $\lambda > 0$ and set $p = \lambda / D$. Then for every fixed $k = 0, 1, 2, \dots$, $$\lim_{D \to \infty} \binom{D}{k}\left(\frac{\lambda}{D}\right)^{k} \left(1 - \frac{\lambda}{D}\right)^{D-k} \;=\; \frac{\lambda^{k} e^{-\lambda}}{k!}.$$
Proof · start with the two cases you can do by hand

The one fact we import from calculus is the definition of $e$: $\displaystyle \lim_{D\to\infty}\left(1 + \frac{x}{D}\right)^{D} = e^{x}$. With $x = -\lambda$ this gives $(1 - \lambda/D)^{D} \to e^{-\lambda}$. Everything else is bookkeeping.

Case $k = 0$. There is only one way to have zero successes: every one of the $D$ trials fails.

$$P(X = 0) = (1-p)^{D} = \left(1 - \frac{\lambda}{D}\right)^{D} \;\longrightarrow\; e^{-\lambda} \;=\; \frac{\lambda^{0} e^{-\lambda}}{0!}. \;\checkmark$$

Case $k = 1$. Choose which trial succeeded ($D$ ways), it succeeds (probability $p$), the other $D-1$ fail:

$$P(X = 1) = D\,p\,(1-p)^{D-1} = \underbrace{D \cdot \frac{\lambda}{D}}_{=\;\lambda} \cdot \underbrace{\left(1 - \frac{\lambda}{D}\right)^{D}}_{\to\, e^{-\lambda}} \cdot \underbrace{\left(1 - \frac{\lambda}{D}\right)^{-1}}_{\to\, 1} \;\longrightarrow\; \lambda e^{-\lambda} = \frac{\lambda^{1}e^{-\lambda}}{1!}. \;\checkmark$$

Notice the manoeuvre in the second line: we rewrote $(1-p)^{D-1}$ as $(1-p)^{D}(1-p)^{-1}$ so that one factor is exactly the limit we know and the other is a nuisance factor tending to 1. That trick is the entire general case.

General $k$. Write the binomial coefficient out and split the powers the same way:

$$\binom{D}{k}\left(\frac{\lambda}{D}\right)^{k}\left(1-\frac{\lambda}{D}\right)^{D-k} = \frac{\lambda^{k}}{k!} \cdot \underbrace{\frac{D(D-1)\cdots(D-k+1)}{D^{k}}}_{\text{(A)}} \cdot \underbrace{\left(1-\frac{\lambda}{D}\right)^{D}}_{\text{(B)}} \cdot \underbrace{\left(1-\frac{\lambda}{D}\right)^{-k}}_{\text{(C)}}.$$

Take the three braced factors in turn, with $k$ held fixed while $D$ grows:

  • (A) is a product of $k$ terms $\frac{D}{D}\cdot\frac{D-1}{D}\cdots\frac{D-k+1}{D}$, each of which tends to 1. A fixed number of factors each tending to 1 has product tending to 1.
  • (B) $\to e^{-\lambda}$, by the definition of $e$.
  • (C) $\to 1^{-k} = 1$, since $\lambda/D \to 0$.

Multiplying, the limit is $\lambda^{k}e^{-\lambda}/k!$. ∎

Assumptions used: $k$ is held fixed while $D \to \infty$; $\lambda = Dp$ is held fixed; the trials are independent and identically distributed (that is what made it a binomial in the first place).

Where "variance = mean" comes from

Now the payoff, and it is a single line. Under the same limit, what happens to the variance?

The coincidence, finally explained  proved $$\mathrm{Var}(X) = Dp(1-p) = \lambda\,(1-p) \;\xrightarrow[\;p \to 0\;]{}\; \lambda = E[X].$$

That is the whole thing. A binomial has variance strictly less than its mean, by exactly the factor $(1-p)$. As $p \to 0$ that factor goes to 1 and the deficit disappears, leaving variance and mean equal.

The Poisson is the distribution whose spread you no longer get to choose. Fix the mean and the variance is determined. Every square root in the remaining thirteen weeks — $d' \propto \sqrt{\text{depth}}$, $d' \propto \sqrt{k}$, the accuracy formula $\Phi(d'/2)$ — descends from this line, and the failure of this line is what Week 11 is about.

It is worth saying loudly what is not going on here. "Variance equals mean" is not a deep truth about counting. It is the vanishing of a specific correction factor $(1-p)$ in a specific limit. If you ever want to know whether the theory should apply to some new situation, the question to ask is not "are these counts?" but "is the $(1-p)$ factor negligible, and are the trials independent?"

How good is the approximation for scRNA-seq? Very.

Take the well-expressed gene from Week 1's exercise 1.1: depth $D = 3000$, per-molecule probability $p = 0.002$, so $\lambda = Dp = 6$.

  • Binomial variance: $Dp(1-p) = 6 \times 0.998 = 5.988$.
  • Poisson variance: $\lambda = 6$.
  • Standard deviations: $2.4470$ versus $2.4495$ — a difference of one part in a thousand.

Pointwise, the two pmfs differ by at most $1.6 \times 10^{-4}$ (you will read this number off Lab 1's readout). The total of all the absolute differences is $9.5\times 10^{-4}$: if you drew a thousand cells you would expect roughly one of them to land on a count where the two models even disagree about the third decimal place.

And $p = 0.002$ is a generous gene. A typical gene in PBMC 3k sits nearer $p = 10^{-4}$, where $(1-p) = 0.9999$. In this application the Poisson approximation is not a convenience; it is better than the measurement.

How close, in general  cited Le Cam's theorem (Le Cam 1960) bounds the error uniformly: if $X \sim \mathrm{Binomial}(D,p)$ and $Y \sim \mathrm{Poisson}(Dp)$, then $$\sum_{k=0}^{\infty}\big|P(X = k) - P(Y = k)\big| \;\le\; 2Dp^{2} = 2\lambda p.$$ For $D = 3000$, $p = 0.002$ this bound is $0.024$ — and the true value, $9.5\times10^{-4}$, is twenty-five times smaller still. We use the bound rather than prove it; the proof is a coupling argument well outside Calculus AB. Note its shape: the error is controlled by $p$, not by $D$.

Lab 1 · The binomial, the Poisson, and the gap between them
Blue bars: the exact binomial pmf $\binom{D}{k}p^k(1-p)^{D-k}$ with $p = \lambda/D$. Orange curve: the Poisson pmf $\lambda^k e^{-\lambda}/k!$. The two parameters $D$ and $\lambda$ move independently; $p$ is whatever it must be. Find the smallest $D$ at which you honestly cannot see a gap, then read the number that says how big it still is.

Three things to take away from playing with it. First, the approximation is bad at $D = 25$, $p = 0.8$ — the binomial cannot exceed $D$, and it visibly piles up against that ceiling, while the Poisson has a tail going off to infinity. Second, the convergence is governed by $p$ alone: at $\lambda = 20$ you need a much larger $D$ to reach the same $p$, and the same $p$ gives you about the same maximum error. Third, at the actual scRNA-seq operating point ($D = 3000$, $\lambda = 6$, $p = 0.002$) the two curves are indistinguishable at any plausible screen resolution, and the readout tells you the disagreement is in the fourth decimal place.

Why $p$ is small in this application

A human cell carries a few hundred thousand mRNA molecules spread over roughly twenty thousand genes. Even a gene making up an unusually large 0.2% of the transcriptome — one molecule in five hundred — gives $p = 0.002$. Most of the genes we will use as markers are ten to a hundred times rarer than that.

So the Poisson limit is not a mathematical idealization we are hoping applies. It is a description of the regime the technology actually operates in, and the honest place to attack this project is not "is $p$ small enough?" (it is) but "are the captures really independent?" (they are not quite, and Week 11 measures how badly).

6  The thinning theorem

Now the result this week exists for. Suppose you have a Poisson number of things, and then you lose some of them at random. What is left?

Theorem · Poisson thinning  proved Let $X \sim \mathrm{Poisson}(\lambda)$, and suppose each of the $X$ items independently survives with probability $q$ and is lost otherwise, independently of $X$. Let $Y$ be the number of survivors. Then $$Y \sim \mathrm{Poisson}(q\lambda).$$ Exactly. Not approximately, not asymptotically, not in the limit of large $\lambda$.
Proof · condition on how many there were to begin with

We want $P(Y = m)$ for a fixed $m \ge 0$. The number of survivors depends on two things: how many items there were ($X = n$), and how many of those survived. So split on $n$, using the law of total probability:

$$P(Y = m) \;=\; \sum_{n=m}^{\infty} P(X = n)\, P(Y = m \mid X = n).$$

The sum starts at $n = m$ because you cannot have more survivors than items. Given $X = n$, the survivors are $n$ independent coin flips with success probability $q$ — a binomial:

$$P(Y = m \mid X = n) = \binom{n}{m} q^{m}(1-q)^{n-m}.$$

Substituting the Poisson pmf for $P(X = n)$:

$$P(Y = m) = \sum_{n=m}^{\infty} \frac{e^{-\lambda}\lambda^{n}}{n!} \cdot \frac{n!}{m!\,(n-m)!}\, q^{m}(1-q)^{n-m}.$$

The $n!$ cancels — this is the step that makes the whole thing work, and it is worth noticing that it cancels because the Poisson pmf and the binomial coefficient contain the same factorial:

$$P(Y = m) = \frac{e^{-\lambda} q^{m}}{m!} \sum_{n=m}^{\infty} \frac{\lambda^{n}(1-q)^{n-m}}{(n-m)!}.$$

Now substitute $j = n - m$ (so $n = j + m$ and $j$ runs from 0 upwards), and split $\lambda^{j+m} = \lambda^{m}\lambda^{j}$:

$$P(Y = m) = \frac{e^{-\lambda}(q\lambda)^{m}}{m!} \sum_{j=0}^{\infty} \frac{\big(\lambda(1-q)\big)^{j}}{j!}.$$

That remaining sum is the Taylor series of the exponential, $\sum_j z^j/j! = e^{z}$, with $z = \lambda(1-q)$. So

$$P(Y = m) = \frac{e^{-\lambda}(q\lambda)^{m}}{m!}\, e^{\lambda(1-q)} = \frac{(q\lambda)^{m} e^{-q\lambda}}{m!},$$

because $e^{-\lambda}e^{\lambda - q\lambda} = e^{-q\lambda}$. That is exactly the $\mathrm{Poisson}(q\lambda)$ pmf. ∎

Assumptions used: $X$ is Poisson; each item survives independently of the others; the survival probability $q$ is the same for every item and does not depend on $X$.

Say this out loud: one theorem, three experiments

The thinning theorem is not a technical lemma. It is the reason this project has one theory instead of three. Every "less data" manipulation you will perform is the same mathematical operation:

  • Lower sequencing depth. Sequencing a library to depth $qD$ instead of $D$ keeps each molecule with probability $q$. New rate: $q\lambda$. Still Poisson. This is why Week 10's protocol — take the real PBMC 3k matrix and downsample it — is legitimate rather than a fudge, and it is downsample_counts in your Python package.
  • Transcript dropout. A molecule fails to be captured, reverse-transcribed or amplified with some probability $1-q$. New rate: $q\lambda$. Still Poisson. So dropout is indistinguishable from shallower sequencing, which is the headline of Week 9 and a genuinely surprising claim to most biologists.
  • Drawing fewer beads. Week 12's physical experiment draws $n$ beads from a jar and then applies a dropout rule with a die. Same theorem, same $q$, and this time nothing is simulated.

Because all three are thinning, all three shift $\lambda$ and nothing else. In Week 3 you will see that $d'$ depends on $\lambda$ through $\sqrt{\lambda}$, so all three cost you separation by the same factor $\sqrt{q}$. Three experiments, one prediction.

Corollary · thinnings compose, and the Fano factor never moves

Thin by $q_1$, then thin the survivors by $q_2$: apply the theorem twice and the result is $\mathrm{Poisson}(q_2 q_1 \lambda)$. So a library sequenced at half depth and then subjected to 30% dropout is exactly a library at rate $0.5 \times 0.7 \times \lambda = 0.35\lambda$, and no experiment can tell the two apart.

And since the result is Poisson at rate $q\lambda$, its variance is $q\lambda$ too — so the Fano factor is $q\lambda/q\lambda = 1$ for every $q$. Thinning cannot create or destroy overdispersion. That flat line is the second figure you produce this week, and it is a much sharper test of your code than "the mean looks about right".

7  Lab: thinning, checked against the theorem

The theorem makes a falsifiable prediction: a Poisson($\lambda$) thinned by $q$ should be statistically identical to a Poisson($q\lambda$) drawn directly. Not similar in mean — identical in distribution. Here are both, on the same axes.

Lab 2 · Two roads to the same distribution
Blue bars: draw $\mathrm{Poisson}(\lambda)$, then flip a coin with probability $q$ for each of the $X$ molecules and keep the survivors. Teal outline: draw $\mathrm{Poisson}(q\lambda)$ directly, never having generated the discarded molecules at all. The theorem says these two histograms are samples from the same law. The Fano factors should both sit at 1 no matter how hard you thin.

Push $q$ down to $0.05$ and look at what survives: the two histograms still agree, and both Fano factors still sit near 1, but the relative noise has exploded. At $\lambda = 100$, $q = 0.05$ the mean is 5 and the standard deviation is $\sqrt{5} \approx 2.24$, so you are reporting a count that is wrong by 45% on a typical cell. Thinning does not break the Poisson structure; it just moves you to a much worse place on the same curve. That is the entire content of "sequencing depth matters".

The mistake this lab is designed to prevent

Almost everyone, on first meeting thinning, does the arithmetic as though it were a scaling: "half the molecules, so half the count, so half the standard deviation." It is not. Halving the rate divides the standard deviation by $\sqrt{2}$, not by 2, because the standard deviation is $\sqrt{\lambda}$.

Concretely: thinning $\lambda = 100$ (sd $10$, relative noise 10%) by $q = 0.5$ gives $\lambda = 50$ (sd $7.07$, relative noise 14%). The absolute noise went down and the relative noise went up. If you cannot say which of those two your argument needs, you cannot yet do Week 3.

8  A numerical warning: compute the pmf in log space

The pmf $\lambda^k e^{-\lambda}/k!$ is a mathematically innocent expression and a numerically catastrophic one. A float64 holds numbers up to about $1.8\times10^{308}$ and down to about $5\times10^{-324}$. At the depths this project uses, all three factors leave that window:

Quantity at $\lambda = k = 5000$Approximate valuefloat64?
$\lambda^{k} = 5000^{5000}$$10^{18494}$overflow to inf
$k! = 5000!$$10^{16326}$overflow to inf
$e^{-\lambda} = e^{-5000}$$10^{-2172}$underflow to 0.0
the answer $P(X = 5000)$$0.0056$perfectly representable

So the probability is an ordinary number near a hundredth, and every single intermediate step in the naive formula is unrepresentable. Evaluate it directly and you get inf/inf, which is nan, which then silently poisons every sum it touches downstream.

The fix, which is also the standard practice

Take the logarithm first, evaluate that, and exponentiate only at the very end:

$$\log P(X = k) \;=\; k\log\lambda \;-\; \lambda \;-\; \log(k!).$$

At $\lambda = k = 5000$ the three terms are about $42586$, $-5000$ and $-37592$ — all comfortable numbers. The factorial is computed as $\log(k!) = \log\Gamma(k+1) = $ scipy.special.gammaln(k + 1), which computes the log of the factorial without ever forming the factorial. That is why gammaln is imported at the top of celldetect/counting.py and why poisson_logpmf exists as a separate function from poisson_pmf.

This is not a stylistic preference. The test test_poisson_logpmf_survives_large_lambda evaluates the log-pmf at $\lambda = 5000$ and asserts every value is finite. An implementation that computes the pmf and then takes its log will fail it.

The same principle recurs three more times in this project: the naive-Bayes classifier in Week 5 adds log-probabilities rather than multiplying probabilities (a product of 2000 gene likelihoods underflows to zero); Week 4's exact Bayes error sums pmfs computed the same safe way; and Week 12's bead likelihoods are handled identically. "Work in logs" is the single most useful piece of numerical hygiene you will learn all semester.

The one that catches everyone in Week 2

Two traps, and the tests are built to catch both.

Trap 1: the same rng, twice. In test_downsample_counts_endpoints, downsample_counts(x, 1.0, rng) must return x exactly and downsample_counts(x, 0.0, rng) must return zeros. If you special-case those and forget to draw from rng anyway, later calls will get different random numbers than the seed implies. Just let rng.binomial handle both endpoints; it does the right thing.

Trap 2: rng.binomial wants integers. A count array that arrived as float64 (very easy after a division) will make numpy raise or silently truncate. Cast with .astype(np.int64), as the docstring says, and then ask yourself where the float crept in.

Sequencing. $E[X] = Dp = 3000 \times 0.002 = 6$. $\mathrm{Var}(X) = Dp(1-p) = 6 \times 0.998 = 5.988$, so $\mathrm{sd}(X) = \sqrt{5.988} = 2.4470$. The Poisson answers are $6$, $6$ and $\sqrt{6} = 2.4495$. The relative error in the standard deviation is $(2.4495 - 2.4470)/2.4470 = 0.10\%$.

Beads. $E[X] = 20 \times 0.3 = 6$ — the same mean. But $\mathrm{Var}(X) = 20 \times 0.3 \times 0.7 = 4.2$, against a Poisson prediction of $6$. The Poisson would overstate the variance by 43%, and the standard deviation by 20%.

Why: the Poisson limit needs $p \to 0$, and $p = 0.3$ is nowhere near zero. The $(1-p) = 0.7$ factor is doing real work. Concretely, the binomial cannot return more than 20 and the Poisson can return 25; the binomial is squeezed against a ceiling the Poisson does not have.

This is exactly why Week 12's bead experiment is analysed with the binomial, not the Poisson, and why the bead chapter has its own version of the $d'$ derivation. The beads are an honest analog of sampling, not of the Poisson limit — and being clear about which parts of an analogy transfer is most of what makes an analogy scientific rather than decorative.

Exercise 2.2★
Carry out the Poisson limit for $k = 2$ explicitly, in the style of the $k = 0$ and $k = 1$ cases: write the binomial probability with $p = \lambda/D$, split the powers of $(1-\lambda/D)$, and identify each factor's limit.
Show solution

With $k = 2$ the binomial coefficient is $\binom{D}{2} = \dfrac{D(D-1)}{2}$, so

$$P(X = 2) = \frac{D(D-1)}{2}\left(\frac{\lambda}{D}\right)^{2} \left(1-\frac{\lambda}{D}\right)^{D-2}.$$

Pull out $\lambda^2/2$ and split the last factor:

$$= \frac{\lambda^{2}}{2} \cdot \underbrace{\frac{D(D-1)}{D^{2}}}_{=\,1 - 1/D \,\to\, 1} \cdot \underbrace{\left(1-\frac{\lambda}{D}\right)^{D}}_{\to\, e^{-\lambda}} \cdot \underbrace{\left(1-\frac{\lambda}{D}\right)^{-2}}_{\to\, 1} \;\longrightarrow\; \frac{\lambda^{2}e^{-\lambda}}{2} = \frac{\lambda^{2}e^{-\lambda}}{2!}.$$

Which is the claim. Note that $2! = 2$ appeared from the binomial coefficient's denominator, not from anywhere exotic.

Doing $k=2$ by hand is what makes the general proof readable rather than symbol-shuffling: factor (A) in the general argument is precisely the $D(D-1)\cdots/D^{k}$ you just wrote as $1 - 1/D$. If you can do $k = 2$ from scratch you can reconstruct the whole theorem at a whiteboard, which is what Week 6's closed-book session will ask of you.

Exercise 2.3★★
Prove directly from the Poisson pmf that $E[X] = \lambda$ and $\mathrm{Var}(X) = \lambda$, without taking any limits. Hint: for the variance, compute $E[X(X-1)]$ rather than $E[X^2]$; the factor $k(k-1)$ cancels beautifully against $k!$.
Show solution

The mean. The $k = 0$ term contributes nothing, so start at $k = 1$ and cancel one factor of $k$ against $k!$:

$$E[X] = \sum_{k=0}^{\infty} k\,\frac{\lambda^{k}e^{-\lambda}}{k!} = \sum_{k=1}^{\infty} \frac{\lambda^{k}e^{-\lambda}}{(k-1)!} = \lambda e^{-\lambda}\sum_{j=0}^{\infty}\frac{\lambda^{j}}{j!} = \lambda e^{-\lambda}e^{\lambda} = \lambda,$$

substituting $j = k-1$ and recognizing the exponential series.

The second factorial moment. The same trick twice; the $k=0$ and $k=1$ terms vanish because $k(k-1) = 0$ for both:

$$E[X(X-1)] = \sum_{k=2}^{\infty} k(k-1)\frac{\lambda^{k}e^{-\lambda}}{k!} = \sum_{k=2}^{\infty}\frac{\lambda^{k}e^{-\lambda}}{(k-2)!} = \lambda^{2}e^{-\lambda}\sum_{j=0}^{\infty}\frac{\lambda^{j}}{j!} = \lambda^{2}.$$

The variance. Since $E[X(X-1)] = E[X^{2}] - E[X]$, we get $E[X^{2}] = \lambda^{2} + \lambda$, and therefore

$$\mathrm{Var}(X) = E[X^{2}] - (E[X])^{2} = (\lambda^{2} + \lambda) - \lambda^{2} = \lambda. \qquad \blacksquare$$

Assumptions used: none beyond the pmf itself and absolute convergence of the series (which holds because $e^\lambda$ converges for every $\lambda$).

Two independent routes to the same fact — the limit of $Dp(1-p)$ in section 4, and this direct sum — is worth having. The limit route tells you why the variance equals the mean (a factor died); the direct route tells you that it is exactly true for the Poisson and not an artefact of the approximation. Week 3's derivation needs the second kind of confidence.

Exercise 2.4★★
A 10x run gives depth $D = 4000$ per cell. You are told the capture efficiency is only 32% — that is, 68% of the transcripts present in the cell never make it into the data. Your collaborator says "so the real depth is 4000, but we only see part of it, and the statistics are ruined." Answer them precisely: what is the distribution of the observed count for a gene at fraction $p = 0.0015$? Then, separately: you want to simulate a 25% dropout rate on top of a downsampling to half depth. What single keep probability is equivalent, and what does that do to the observed rate?
Show solution

The collaborator. The statistics are not ruined; they are relabelled. If the cell's true content gives a Poisson rate and each molecule survives capture independently with probability $q = 0.32$, the thinning theorem says the observed count is still Poisson, with rate $q\lambda$. The number to quote is the effective depth $qD = 0.32 \times 4000 = 1280$ molecules, so for this gene $\lambda_{\text{obs}} = 1280 \times 0.0015 = 1.92$ counts. Everything downstream — Fano factor, $d'$, accuracy — is computed from $1.92$ and is exactly as valid as if the sequencer had been perfect at depth 1280.

What is lost is only the rate itself, not the model: relative noise is $1/\sqrt{1.92} = 72\%$ instead of $1/\sqrt{6} = 41\%$.

Composing thinnings. Downsampling to half depth is $q_1 = 0.5$; 25% dropout is $q_2 = 0.75$. Applying the theorem twice gives a Poisson at rate $q_2 q_1 \lambda = 0.375\lambda$, so the single equivalent keep probability is $q = 0.375$. The observed rate is $0.375$ of what it was; the standard deviation is $\sqrt{0.375} = 0.61$ of what it was; the relative noise is $1/\sqrt{0.375} = 1.63$ times worse.

This exercise is Week 9 in miniature. The claim "dropout is just less depth" sounds glib and is in fact a theorem, and the whole of Week 9 is spent finding the regime (very low $\lambda$) where the downstream consequences stop matching, even though the thinning statement itself never fails.

Exercise 2.5★★
Prove the superposition theorem: if $X_1 \sim \mathrm{Poisson}(\lambda_1)$ and $X_2 \sim \mathrm{Poisson}(\lambda_2)$ are independent, then $X_1 + X_2 \sim \mathrm{Poisson}(\lambda_1 + \lambda_2)$. Then use it to say what the distribution of a cell's total count over all $G$ genes is, and what that means for the assumption "$D$ is fixed".
Show solution

The proof. Split on how the total $n$ was divided:

$$P(X_1 + X_2 = n) = \sum_{k=0}^{n} P(X_1 = k)P(X_2 = n-k) = \sum_{k=0}^{n} \frac{\lambda_1^{k}e^{-\lambda_1}}{k!}\cdot \frac{\lambda_2^{n-k}e^{-\lambda_2}}{(n-k)!}.$$

Multiply and divide by $n!$ to manufacture a binomial coefficient:

$$= \frac{e^{-(\lambda_1+\lambda_2)}}{n!}\sum_{k=0}^{n}\binom{n}{k}\lambda_1^{k}\lambda_2^{n-k} = \frac{e^{-(\lambda_1+\lambda_2)}(\lambda_1+\lambda_2)^{n}}{n!},$$

by the binomial theorem. That is the $\mathrm{Poisson}(\lambda_1+\lambda_2)$ pmf. Independence was used in the very first equality. ∎

The consequence. If every gene's count is independently Poisson with rate $\lambda_g$, the library size $D = \sum_g X_g$ is Poisson with rate $\Lambda = \sum_g \lambda_g$ — a random variable, not a fixed one. So the two models ("$D$ fixed, counts multinomial" and "counts independently Poisson, $D$ random") are not the same model, though they are famously close: conditioning the Poisson model on $\sum_g X_g = D$ returns exactly the multinomial model.

This is the "Poissonization" argument, and it is why single-cell papers move between the two descriptions without comment. For our purposes the important direction is: because the relative variation in $\Lambda$ is $1/\sqrt{\Lambda} \approx 1/\sqrt{3000} = 1.8\%$, treating $D$ as fixed costs essentially nothing — which is a much better justification for assumption (iii) in section 3 than "we assumed it".

Exercise 2.6★★★
In the thinning setup, let $Y$ be the survivors and $Z = X - Y$ the losses. Prove that $Y$ and $Z$ are independent, with $Y \sim \mathrm{Poisson}(q\lambda)$ and $Z \sim \mathrm{Poisson}((1-q)\lambda)$. Then explain, in one paragraph aimed at a biologist, what this means for the reads a downsampling protocol throws away.
Show solution

The joint pmf. The event $\{Y = m, Z = r\}$ requires $X = m + r$ and then exactly $m$ of those $m+r$ items surviving:

$$P(Y = m, Z = r) = P(X = m+r)\binom{m+r}{m}q^{m}(1-q)^{r} = \frac{e^{-\lambda}\lambda^{m+r}}{(m+r)!}\cdot\frac{(m+r)!}{m!\,r!}q^{m}(1-q)^{r}.$$

The factorials cancel, and splitting $\lambda^{m+r} = \lambda^m \lambda^r$ and $e^{-\lambda} = e^{-q\lambda}e^{-(1-q)\lambda}$ gives

$$P(Y = m, Z = r) = \underbrace{\frac{(q\lambda)^{m}e^{-q\lambda}}{m!}}_{\text{Poisson}(q\lambda)} \cdot \underbrace{\frac{\big((1-q)\lambda\big)^{r}e^{-(1-q)\lambda}}{r!}}_{\text{Poisson}((1-q)\lambda)}.$$

The joint pmf factors into a function of $m$ times a function of $r$, and each factor is a legitimate pmf summing to 1. That is precisely the definition of independence, and it simultaneously identifies both marginals. ∎

For a biologist. When you downsample a library, the reads you discard carry no information whatsoever about the reads you kept. Knowing that a cell lost 900 molecules tells you nothing about how many it retained. This is not obvious and it is not true in general — for a fixed total of 1000, losses and keeps are perfectly anticorrelated — but it is true here, because the total was itself Poisson. It is the reason a downsampled dataset is a legitimate stand-in for a genuinely shallower experiment rather than a strange, correlated shadow of the deep one.

This is the single strongest justification for Week 10's protocol, and it is worth being able to state at the poster session in Week 15, because "you just threw away data, how is that the same as sequencing less?" is the most likely sharp question you will get. The answer is one sentence: the kept and the discarded counts are independent Poissons, so the kept half is distributed exactly as a real shallow run.
